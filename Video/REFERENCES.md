### R6 오늘코딩 — 기본 틀

- **배경:** 남색→짙은 회청색 그라데이션, 우상단에 노란 빛 번짐. 전 구간 같은 배경.
- **상시 요소:** 좌상단 장면 제목(왼쪽에 노란 세로 막대 + 흰 굵은 글씨, 아래에 회색 부제 한 줄). 우상단 챕터 배지(노란 사각형 안 번호 `02` + 회색 챕터명).
- **자료 카드:** 화면 가운데 둥근 모서리 카드(약 화면 폭 65%), 그림자. 카드 아래 오른쪽에 작은 출처 표기.
- **자막:** 하단 중앙 한 줄, 흰 굵은 고딕, 반투명 어두운 띠 위.
- **챕터 전환:** 노란 그라데이션 면이 사선으로 화면을 덮었다가 빠지고, 남은 어두운 면에 큰 금색 번호(`02`). 챕터 시작 직전에 자료 카드 여러 장이 3D로 기울어 떠 있는 몽타주가 사선 사이로 지나간다. 영상에서 유일하게 움직임이 큰 구간.
- **도입:** 첫 50초에 영상 전체 사건을 압축해 말하고 "바로 시작합니다"로 들어간다.

### R4 어도비 — 자막

- 하단 중앙 한 줄, 흰 일반 굵기 고딕, 그림자 약간, 배경 띠 없음. 화면 높이의 약 4%.
- 문장이 길면 두 컷에 걸쳐 같은 줄을 유지한다(자막 하나가 컷보다 길 수 있다).
- 화면은 작업 화면 녹화가 대부분이고, 인물·손 클로즈업이 사이사이 짧게 들어간다.
- 비교가 필요할 때는 화면을 반으로 나누고 각 반에 작은 흰 라벨(`30fps` | `10fps`)만 단다.

### R3 Nine Sols — 트레일러

- 내레이션 없음. 첫 몇 초 컷신 일러스트 → 플레이.
- 문구 카드 3번: 작은 라벨 + 자간 넓은 대문자 제목(`Master the / ART OF DEFLECTION`, `Slay the / NINE SOLS`). 플레이 화면 위 중앙, 별도 배경 없음.
- 마지막: 밝게 날린 키아트 위에 타이틀 → 스토어 로고 → 검은 화면.

### R7 코브 — 메탈슬러그 소개

- 플레이 영상은 화면 가득. 우상단 원형 채널 로고 상시.
- 자막: 하단 중앙 흰 글씨 + 아래쪽 어두운 그라데이션 띠. 기울임 서체.
- 컷이 빠르다(평균 2.5초). 로고·하드웨어·관련 실사 사진 인서트를 자주 섞는다.
- 사선으로 화면이 갈리는 전환이 가끔 보인다.

### R8 Brackeys — 에디터 설명

- 개념을 먼저 카드로: 보라 그라데이션 배경 + 평면 아이콘 + 자간 넓은 대문자 라벨. 예: 아이콘 다수 → `LEVEL 1` 점선 박스로 묶기 → `LEVEL 1 / LEVEL 2` 각각 `COIN` 두 개. 챕터 표지(`TILES`)도 같은 배경.
- 이후 에디터 실화면 롱테이크(수 분 단위, 화면 전환 거의 없음). 꾸밈 없이 전체 화면.
- 내레이션은 "Godot에서는 노드로 만든다 → 노드는 종류가 많다"처럼 한 개념씩 쌓는다.

### R1 jdh / R2 I/O — 데브로그

- R1: 검은 바탕 위에 화면 캡처·영상 창을 기울여 띄우고, 고정폭 서체 짧은 농담 캡션을 얹는다. 커밋 로그·코드 창이 자료로 자주 나온다. 도입에서 "지난 영상 끝엔 이랬고 지금은 이렇다"로 결과부터 보여 준다.
- R2: 다른 게임·밈 클립이 많고, 큰 흰 글씨 한 줄로 핵심 공식(`Player Velocity == Dash Speed`)을 화면 중앙에 띄운다. 챕터 카드는 검은 화면 + 흰 단어. 도입 첫 문장이 질문형 갈고리("한 판 30초짜리를 10시간 하게 만든 방법").

## 새 영상 원칙 (갱신)

1. **틀은 R6.** 남색 배경, 좌상단 장면 제목, 우상단 챕터 배지, 가운데 자료 카드, 강조는 노란색 한 가지.
2. **자막은 R4.** 하단 중앙 한 줄, 흰 고딕, 띠 없이 약한 그림자. R6의 반투명 띠는 플레이 화면이 밝을 때만 쓴다.
3. **플레이 장면은 R7.** 카드에 넣지 않고 화면 가득. 우상단에 작은 배지만.
4. **에디터 설명은 R8 → R6.** 개념 카드(평면 아이콘, R6 색으로) → 에디터 실화면 → 게임 결과.
5. **챕터 전환은 R6 사선 와이프 + 큰 번호.** 영상에서 움직임이 큰 곳은 여기뿐이다.
6. **시작·끝은 R3.** 내레이션 없는 플레이 몽타주 + 라벨/대문자 제목 문구, 마지막 타이틀.
7. **도입은 R2·R6처럼 결과부터.** 첫 30초 안에 완성된 게임과 에디터를 먼저 보여 주고 "어떻게 만들었는지"로 들어간다.
8. **모션은 R4 수준.** 컷과 페이드 위주. 비교는 화면 반분할 + 작은 라벨.
