디버그 / 에디터

실행 인자로 --editor를 넣으면 디버그·에디터 모드로 실행됩니다.

에디터는 Dear ImGui로 개발했습니다.

에디터는 네 가지로 나뉩니다.

애니메이션 에디터: 스프라이트 위치를 조절해 애니메이션을 다듬습니다.

맵 에디터: 오브젝트를 직접 배치해 기획대로 스테이지를 구성합니다.

픽셀 충돌체 에디터: 충돌 영역을 직접 그려 원하는 충돌을 만듭니다.

게임 플레이 에디터: 조작과 적 AI를 보며 데이터를 바로 조절합니다.

게임의 상당 부분을 데이터 중심으로 만들어, 수치와 배치를 JSON으로 저장하고 다시 읽습니다.

애니메이션과 튜닝 값은 바로 반영되고, 맵과 충돌 데이터는 빌드 없이 다음 실행에 반영됩니다.

메탈슬러그는 스프라이트가 방대해 리소스 작업량이 어마어마합니다.

미리 정리한 스프라이트 시트를 불러와 편집합니다.

어니언 스킨으로 직전 프레임을 반투명하게 겹쳐 보며 맞춥니다.

픽셀 게임은 1픽셀 차이도 손맛을 바꿔, 프레임마다 위치를 세밀하게 조절합니다.

애니메이션 속도도 프레임 단위로 조절합니다.

캐릭터뿐만 아니라 적 유닛도 같은 방식으로 프레임마다 맞춥니다.

한 장면에도 오브젝트가 엄청나게 많아, 직접 배치하고 섹션을 나누는 도구가 필요했습니다.

적을 골라 원하는 위치에 바로 배치합니다.

우르르 나오는 적, 특정 위치의 탱크와 헬기, 펑펑 터지는 나무 구조물까지

모두 이 에디터에서 편집합니다.

스테이지 전체를 둘러보며 섹션 구간을 확인하고,

섹션을 선택하고 노란 시작선을 드래그해, 적이 나오는 위치를 옮깁니다.

플레이어가 이 선을 넘으면 그 섹션의 적이 나타납니다.

화면에 보이지 않는 충돌 이미지가 사선과 곡선 충돌을 만듭니다.

발밑 픽셀을 읽어, 흰색은 빈 공간, 파란색은 바닥으로 처리합니다.

OBB 충돌체도 있지만, 복잡도를 생각하면 픽셀 방식이 더 단순합니다.

보이는 맵 위에 직접 충돌 영역을 그려, 둘을 정확히 맞춥니다.

사각형, 선, 채우기 도구로 칠하고 저장합니다.

칠한 영역이 그대로 캐릭터가 밟는 바닥이 됩니다.

히트박스, 투사체 발사 위치, 몬스터 패턴 같은 값을 모두 데이터로 분리했습니다.

에디터에서 조절한 값은 다시 빌드하지 않고 바로 확인합니다.

병사부터 탱크, 보스까지 유닛마다 같은 화면에서 편집하고 확인합니다.

메탈슬러그는 오브젝트가 부위별로 잘게 나뉘어 있어, 세세한 편집이 꼭 필요했습니다.

투사체 수, 폭발 크기와 위치, 간격 같은 값도 바로 조절합니다.

몬스터의 충돌체를 추가하고, 적을 배치하며 AI 동작을 확인합니다.
