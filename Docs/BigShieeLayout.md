# Big Shiee 배치 레이아웃 (원본 영상 대조)

산출물: `Assets/Defs/BigShieeLayout.json`. 원본 영상: `Assets/Source/videoplayback (1).mp4` (496x360, 30fps, 전체 388초).
스프라이트 크기는 모두 게임 px(시트 2x 배율 적용 후). 모든 피벗은 `center` 이므로 offset 은 "파츠 프레임 중심 - 본체 프레임 중심" 이다.

## 1. 축척과 원점

- 영상→게임 축척: `scaleToVideo = [0.82, 0.80]` (영상 px 당 게임 px 의 역수 아님. 영상 px = 게임 px × 0.82 (x), × 0.80 (y)).
  즉 게임 px = 영상 px ÷ 0.82 (x), ÷ 0.80 (y) → 약 ×1.22 (x), ×1.25 (y). 가로/세로가 다르다.
  신뢰도: 중간. `BigShiee_Cannon_Idle` 과 `BigShiee_Cannon_Deploy1/6` 이 같은 축척에서 가장 높은 점수를 냈다.
  640/496=1.29, 448/360=1.24 이므로 영상이 게임 화면 전체인지 크롭인지 확정할 수 없다. 여기서는 영상 (0,0) = 게임 화면 (0,0) 으로 가정했다 (크롭 오프셋 미확인).
- 본체 원점 `screenOrigin = [290, 208]` (게임 640x448 기준, t=321 idle). 신뢰도: 낮음~중간.
  - 근거: `Cannon_Idle` 프레임 중심(596x416)이 t=321 영상에서 영상 좌표 (x=-7..482, y=0..333) 에 맞음. 중심 = (237.5, 166.5) 영상 px → ÷(0.82,0.80) → (290, 208).
  - 보스는 움직인다. 같은 Cannon 포즈에서 t=312 (`Deploy1`) 원점 ≈ (262,208), t=314 (`Deploy6`) ≈ (248,208), t=330 (`Cannon_Idle`) ≈ (205,208). 가로로 약 80px 이동하므로 원점은 포즈/시간마다 달라진다. JSON 의 원점은 t=321 기준 하나만 둔다.
  - 세로는 거의 고정(208 근처)이다.

## 2. 포즈

### idle (`BigShiee_Body_Idle`, 542x416)
- Body_Idle 의 프레임 0 은 캐논이 접힌 상태다. 영상 t=321 은 캐논이 전개된 상태이므로 idle 포즈로 t=321 을 증명할 수 없다. 원점 증거로만 쓰지 않는다.
- 파츠: `Emblem_Spin_A` offset (245,25), 신뢰도 중간. `Turret_A_Idle` (161,-43), 신뢰도 낮음.

### cannon (`BigShiee_Cannon_Idle`, 596x416) — 영상 t=321 과 가장 잘 맞는 포즈
- 캐논(스컬 헤드)과 오른쪽 상단 구조가 이미 본체 프레임에 구워져 있다. 따로 올릴 필요가 없다.
- 파츠: `Emblem_Spin_A` (245,25) 신뢰도 중간. X 엠블럼 위치가 영상과 일치한다 (검증 합성에서 확인).
  `Gun_Aim` (99,-66) 신뢰도 낮음. 이 오버레이는 본체에 이미 있는 헤드와 겹친다. 검증 합성에서 "SHOOTING" 라벨 조각이 보인다 (아래 문제 참조).

### destroyed (`BigShiee_Destroyed_Body`, 단일 프레임)
- 영상 t=372/376 과의 템플릿 매칭 점수가 0.17~0.18 로 실패. 위치 미확인. 파츠 offset 도 `null` (unknown).
- 시간 근거: 영상에서 파괴 장면은 t≈372~376 으로 추정했으나 프레임 수준 확인은 하지 않았다.

## 4. 발사 포인트 (muzzles)
- `cannon_mouth` offset (37,-106), 방향 (-1,0), 신뢰도 낮음. 스컬 헤드의 포구는 영상 (≈268,82) 으로 추정. 검증 합성에서 대략 맞음.
- 주황 셸, 청록 트레이서 출처는 분석하지 않았다 (`unknown`).

## 5. 히트박스 (스프라이트 알파 기준, 본체 중심 상대, 게임 px)
- `hull`: x[-298,298] y[22,208] (프레임 하단 230 행 이후 알파 bbox), 역할 body. 추정치.
- `cannonHead`: x[0,268] y[-176,22] (프레임 우상단), 역할 main_gun. 추정치.
- `turretCluster`: x[-246,0] y[-208,22] (프레임 좌상단), 역할 turrets. 추정치.

## 6. 검증
- `Docs` 용 검증 합성: t=321 영상을 게임 px 로 확대한 뒤 `Cannon_Idle` 본체 + `Emblem_Spin_A` + `Gun_Aim` 을 50% 투명도로 얹었다.
  엠블럼, 캐논 헤드 위치는 맞음. 하단 캐터필러/트레드는 합성이 영상보다 약 8~10px 아래에 있다. 세로 축척 0.80 이 약간 커 보인다. 값은 수정하지 않았다.

## 7. 핵심 프레임 타임스탬프
- t=321.0 s: 캐논 전개 idle. 원점, 축척, 엠블럼 기준.
- t=312.0 s: 캐논 전개 시작 (`Cannon_Deploy1`). 원점 (262,208), 신뢰도 낮음.
- t=314.0 s: `Cannon_Deploy6`. 원점 (248,208), 신뢰도 낮음.
- t=330.0 s: `Cannon_Idle` 보스 이동. 원점 (205,208), 신뢰도 낮음.
- t=372~376 s: 파괴 장면. 매칭 실패, 미확인.

## 8. 알려진 문제
- (해결) `BigShiee_Gun_Aim` 1번 프레임의 "SHOOTING" 라벨 조각: 높이 150 → 138 로 잘랐다 (`sheets.json`). 영역 exclude 는 쓰지 않았다 (Gun_Aim 본체가 같은 영역에 있다).
- (해결) 사망 연출 `BigShiee_Smoke` 0,1 프레임이 시트 legend 의 어두운 원/흰 원 (약 96 px 디스크, 플래시처럼 보임): 두 프레임을 뺐다.
- 영상 원점 매핑(크롭 오프셋) 미확인. 원점 절대값은 ±10px 정도 흔들릴 수 있다.
- 파괴 포즈와 터릿 B~G 위치는 미확인.

## 9. 최종 배치 (구현 반영, 2차 검증)

- 런타임 값의 원본은 `Assets/Defs/Boss.json` 의 `bigshiee.params` 다 (원점 기준). 위 §4 의 포구 (37,−106) 와 §5 의 히트박스는 **대체**되었다 (구 값은 잘못 잡힌 머리 위치였다).
- 원점: 발 − (0, 208). 화면 중심 x = 470 (home, 플레이 테스트 후 변경. 구 값 290), 주행 445~495 (±25). 플레이어 벽 = 아레나 왼쪽 + 165 (고정). 선체 프레임 왼쪽 끝 (x−271) ≥ 174.
- 포탑/캐논 상대 좌표는 원점 기준이라 home 이 바뀌어도 그대로 따라간다 (화면 x 는 +180).
- 검증 캡처 (Release, `--warp-boss --hold Right`): `Captures/v8w` 에서 플레이어가 13619 (= 아레나 13454 + 165) 에 멈춘다. `Captures/v8` 120~1500 틱에서 HP 바가 상단 y 56 에 보이고 점수/타이머와 겹치지 않는다.
- 캐논 헤드: `BigShiee_Gun_Aim` / `Gun_Shoot_k` 의 피벗 = 원점 기준 (−108, −48). 포구 (−173, −64). 피격 상자 120x155 @(−133, −75). Cannon_Idle 프레임 위에 Gun_Shoot_1 을 얹은 합성과 디버그 상자 캡처로 확인했다.
- 포탑 중심 (원점 기준): A (−130,−108), B (−8,−146), C (52,−33), D (−48,−28), E (150,−14), F (85,24), G (−76,−90). 피격 상자 64x50. 디버그 상자가 포탑 아트 위에 놓인다. 원작 정확 위치는 미확정.
- 선체 상자 560x330 @(0, 43). 엠블럼 스핀 오버레이 (245, 25) 는 정적 X 엠블럼 위에 얹힌다.
- 검증 캡처 (Release, headless, `--warp-boss`): `Captures/bs1` (등장 20–160, 연사 300–800), `Captures/bs2` (연사 240/420), `Captures/bs3` (캐논 전개 215/380/440, 조준 470, 사격 505, 착탄 560/610 — 임시로 연사 1 s, 트레이서 0, 주황 포탄 매 볼리로 조정한 빌드), `Captures/bs4` (사망 300–800, 임시 HP 40 + `--hold J`; 800 에 완료 화면). 임시 조정은 캡처 후 원복했다.
- 미확인: 포탑 파괴 잔해 (`Turret_X_Destroyed`) 장면 캡처 (코드 경로는 `EachTurretDiesOnItsOwnAndTheHullKeepsItsHealth` 테스트가 덮는다), 주황 포탄 착탄 폭발의 그래픽 위치 (판정 상자는 플레이어 x 에 맞췄다).
