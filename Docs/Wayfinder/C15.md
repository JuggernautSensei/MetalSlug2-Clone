# C15 보스 진입 구간 진단·수정

증상: 보스 등장 시 바닥의 소품이 그 자리에서 사라지고, 카메라가 튄다.

## 원인 (덤프로 확인)

재현 도구: `C15_DUMP=<csv 경로>` 환경 변수를 주고 `SlugTest --gtest_filter=*BossEntryDump*` (창 없음, 봇이 실제 스테이지를 걸어 보스 아레나까지 진입). 틱별 카메라/락/보스와 소품·아이템 제거 이벤트(화면 안이었는지 포함)를 CSV 로 남긴다. 전/후 덤프: `C15_dump_before.csv`, `C15_dump_after.csv`.

1. 카메라 한 틱 점프 (246 px). 보스 락 사각형 [13700..14340] 은 월드 경계 (배경 폭 14094) 밖으로 나간다. 락 글라이드의 도착점과 렌더 클램프가 월드 경계에 막혀 중심 x 가 13774 (화면 왼쪽 13454) 에서 20틱 멈춘 뒤, 글라이드가 끝나 락이 적용되는 틱에 렌더 왼쪽이 13454 -> 13700 으로 한 번에 점프했다.
2. 그 점프가 컬링을 건드린다. 컬링은 `pos.x < cameraLeft - cullMargin` 만 보므로 점프한 틱에 big_house (x 13542, 폭 498, 화면에 보이던 중) 가 지워졌다. 같은 규칙으로 샤루비아 구간에서도 big_house (x 12518) 가 일부가 화면에 남은 채 지워졌다.
3. 보스 미사일/폭발은 소품을 부수지 않는다: `CanTeamHit(Enemy, Neutral) == false`, 소품 hurtbox 는 Neutral. 의도된 동작이므로 변경 없음.
4. 아이템: 컬링 규칙 (`feet.x < cameraLeft - 50`) 은 아이템 폭 (<= 32 px) 보다 커서 화면 안에서 지워질 수 없다. 덤프에 화면 안 컬링 0건. 단, 스테이지가 놓은 아이템도 15 초 (`kItemLifetimeSec`) 가 지나면 제자리에서 사라진다 (보스와 무관, 의도 여부는 사용자 결정).

## 수정

- `Camera::GetTargetRect_`: 잠금 글라이드 중에는 월드 경계에 곧 적용될 잠금 사각형을 합친 영역을 목표 영역으로 쓴다 (도착점 + 렌더 클램프). 사각형이 월드 안에 있는 다른 락 (버스/헬기/사루비아) 은 합쳐도 같아서 동작이 변하지 않는다.
- `PropWorld::Tick`: 앵커 규칙을 통과해도 스프라이트 오른쪽 끝이 화면 왼쪽 (`cameraLeft`) 보다 오른쪽이면 지우지 않는다. `GetVisualBounds` 와 `SetSpriteLibrary` 추가 (스프라이트 크기 조회). StageState 는 스프라이트 라이브러리 JSON 을 헤드리스에서도 읽는다 (컬링 결과가 모드와 무관하도록).
- 보스 자동 스크롤 램프업: 20 px/s (0.33 px/틱) 로 시작하는 정도라 불연속이 아니므로 추가하지 않았다.
