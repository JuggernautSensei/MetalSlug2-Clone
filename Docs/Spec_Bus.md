# 버스 중간보스 (원작 MS2 Mission 4) 실측 사양

대상: `Assets/Source/videoplayback (2).mp4` (원작 2P 플레이, 480x360, 29.5 fps, 1 frame = 33.9 ms).
좌표 변환: 영상 px → 게임 px 는 x ×1.333, y ×1.244 (640x448). 시간은 영상 초.
스프라이트 크기는 `Assets/Baked/sprites.json` / `anim.json` 값이며 **게임 px = 베이크 값** (시트 1x 의 2배).
신뢰도: [H] 프레임 단위 확인, [M] 0.1~0.5 s 샘플 또는 추정 보강, [L] 육안 1~2 프레임 근거.

## 0. 핵심 결론 (실측과 현재 구현의 차이 요약)

1. 버스는 **이동해 들어오지 않는다.** 월드상 거의 정지 (스크린 속도 ≈ 카메라 팬 속도, 차이 ±20 영상px/s). 68.4~70.3 s 카메라가 우측으로 팬하면서 버스가 화면 우측에서 드러난다. [M]
2. 카메라 락은 70.3 s, 팬 총량 약 213 영상px = 284 게임px (약 1.9 s). 현재 명세의 "1 s 이동" 과 다르다. [M]
3. 전투 중 버스는 **포탄/병사를 발사하지 않은 것으로 보인다** (0.5 s 격자 및 흰 블롭 추적 확인, 이동 발사체 없음). 현재 구현의 shell/soldier 는 원작과 다를 가능성이 높다. [M]
4. 피격 플래시는 **전체 스프라이트 주황 블링크** (3프레임 on / 3프레임 off ≈ 0.2 s 주기). 1회 점멸이 아니다. 상세는 `Docs/Spec_HitFlash.md`. [H]
5. 사망 ≈ 80.0 s, 전투 시간 ≈ 9.5 s (70.4 → 80.0). 현재 TTK 25 s 는 원작의 약 2.6 배. 단 P1 HMG 소모량으로 보면 P1 단독 약 150 dmg, 2P 합산 시 약 250~300 이므로 HP 250 은 2P 기준으로는 맞다. [M]
6. GO! 화살표는 55~113 s 구간 샘플 (0.5~1 s 간격) 에서 찾지 못했다. [M, 부재 확인]

## 5. 전투 방식 (관찰)

- 플레이어 P1 HMG 단독 사용 (BOMB 미사용, ARMS 424→336 = 88 발 / 11.5 s ≈ 7.7 발/s).
- 사거리: P1 은 버스 좌측 약 255 영상px (≈340 게임px) 에서 사격 (74 s 기준). 원거리 사격.
- 74 s 이후 주변 적 (지프/병사) 과 교전 병행 (화면 좌측 병사 여러 명, 흰 블롭은 적 명중 흔적일 가능성).

## 6. HP 추정

- P1 HMG 2 dmg/발 가정, 70.5~80.0 구간 탄 소모 약 73 발 → P1 단독 약 146 dmg (명중률 100% 가정, 실제 명중률 낮으면 HP 더 낮음).
- 2P 가 대등하게 쐈다면 합계 약 290 dmg → HP 250~300 범위와 일치.
- 결론: HP 250 을 유지해도 된다 (2P 전투 기준 TTK 약 10 s). 현재 TTK 25 s 는 2 배 이상 길다. 1P 전투를 기준으로 삼으면 HP 는 150 이 맞다.

## 7. 미확인/한계

- 배경 카메라 추적: 템플릿 매칭 (배경 바위/램프 기둥). 팬 속도 ±15% 오차.
- 세로 좌표는 영상 y 스케일 1.244 가정 (영상 상·하 여백 여부 미검증). 버스 바닥 y 는 ±20 게임px 불확실.
- Begin 프레임 f1~24 는 픽셀 완전 일치하지 않음 (근사 위치). 개방 연출은 OPENING 행 (시트 y≈150~370) 으로 추정.
- 병사/포탄 발사 여부는 0.5 s 샘플과 흰 블롭 추적 근거. 프레임 단위 확인 안 함.
- 잔해 위로 올라갈 수 있는지 (단차 56 px, EnemySpecs §3.1) 는 영상에서 확인하지 못함.
- 탱크/지프 (100~123 s) 의 피격 플래시는 정성 관찰만 (정량 측정 안 함).
