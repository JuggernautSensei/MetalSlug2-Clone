# Boss Shiee 배치 (최종 수치, 실측 근거)

범위: 게임 안 좌표 (`Assets/Defs/Boss.json` `boss_shiee.params`, 원점 = 발 − (0, 208)). 스프라이트 클립 표는 `Docs/BossSheet.md`, 동작 사양은 `Docs/EnemySpecs.md` 3.2, 원작 타임라인은 `Docs/Spec_Boss.md`. 기록 파일: `Assets/Source/BossLayout.json` (게임은 읽지 않는다).

## 1. 선체 ↔ 원작 영상
- 방법: `Body_Idle` 프레임 0 (542x416, 원점 = 셀 중심) 을 원작 `videoplayback (2).mp4` 와 SIFT + RANSAC 으로 맞춘 결과 (t=280, 73 inlier). 변환: video = 1.579 x sheet + (69.9, −39.7), 즉 게임 px 당 0.79 video px (x, y 동일).
- 검증: t=300 프레임 위에 같은 변환으로 선체와 포탑 상자를 겹쳐 보았다 (`Captures/boss/align_t300_check.png`). 선체 외곽, 꼬리 트랙, 오렌지 선수 돔, X 엠블럼 위치가 맞는다. 선체는 t=280 → 300 사이에 육안으로 움직이지 않았다.
- 결과: 선체는 화면상 정지 (전투 중 카메라 자동 전진과 같은 양만큼 월드에서 전진), 등장 때만 화면 왼쪽 밖에서 들어온다 (`entranceFromX` −260, `stationX` 330).

## 2. 포탑 A..G (파트 0..6)
육안 합성으로 배치 (t=300 프레임의 포구 있는 마운트 위에 `Boss_Turret_X_Idle` 프레임 0 을 올려 확인). 원점 기준 중심 (게임 px):

| 포탑 | x | y | 비고 |
|---|---|---|---|
| A | −130 | −108 | 좌상단 스파이크 돔 (화면 좌상) |
| B | −8 | −146 | 상단 중앙 줄무늬 구조 |
| C | 52 | −33 | 중앙 돔 |
| D | −48 | −28 | 중앙 좌 |
| E | 150 | −14 | X 엠블럼 위쪽 우측 |
| F | 85 | 24 | 중앙 우 하단 |
| G | −76 | −90 | 좌 중앙 |

- 피격 상자: 중심 x ±32, 중심 y −25 부터 발 (기둥). 아래에서 위로 쏜 탄 (플레이어 피스톨 상향 조준) 이 선체 몸통보다 먼저 파츠에 닿도록 한다.
- 사격 포구: 중심 + (−40, −10) (왼쪽 발사).
- 한계: 포탑 아트는 선체 프레임에 없다 (템플릿 매칭 실패). 위치는 육안 기준이라 ±10 px 수준으로 본다.

## 3. 스컬 캐논 헤드
- `Boss_Cannon_Idle` 프레임 0 (596x416, 피벗 중심 (298,208)) 을 격자로 읽었다 (`Captures/boss/cannon_idle_grid.png`). 황금 헤드 (상단 중앙 탑, x 240–330, y 0–200) 중심 ≈ 원점 + (−38, −110).
- 캐논 피벗 (`cannonOffset`) (−38, −110), 포구 (`cannonMuzzle`) (−70, −120), 피격 상자 중심 (−38, −110) 크기 100x150 (기둥: 상단 −185 부터 발까지).
- 볼리 예고 `Boss_Gun_Aim` 은 같은 피벗에 그린다 (영상 육안 확인은 못 했다: 캐논 전개는 원작 300 s 근처).

## 4. 선체 상자
- 피격 상자 520x400 (원점 중심). 탄/폭탄 흡수 전용. 파츠 상자보다 나중에 등록 (HitResolver 는 먼저 맞은 한 상자만 피해).

## 5. 알려진 차이 / 미확인
1. 포탑 위치: 육안 합성 (±10 px). 원작의 포탑 A..G 대응은 확정하지 못했다.
2. 캐논 황금 헤드 위치: 프레임 격자 읽기 (±15 px). 원작 전개 장면과 직접 대조하지 않았다.
3. 선체 전진 속도 18 px/s 와 총량 700 px 은 설계값 (원작은 버스트 16–21 px/s, 총 1021 game px 이지만 선체는 화면 정지).
4. 피격 플래시: 파츠별 블링크 (원작 실측 없음).
5. 엠블럼 스핀 (`Boss_Emblem_Spin_A`) 은 그리지 않는다 (장식).
