# 원작 재현 리메이크 계획

원작 참고: `Assets/Source/videoplayback (1).mp4`, `videoplayback (2).mp4` (Mission 4 전체 플레이, 각 약 6분 30초).
스타일: `Docs/CodingStyle.md` (JamEngine / JugGfx / JugX 기준). 새로 쓰거나 다시 쓰는 코드는 모두 이 규칙을 따른다.

## 역할

- 계획, 원작 대비 평가, 승인 요청: Opus (메인 세션)
- 영상 분석, 시트 재절단, 코드 수정, 플레이 캡처: Sonnet 서브에이전트

## 검증 루프 (항목마다 반복)

1. 원작 영상에서 해당 장면 구간을 프레임 단위로 추출한다 (`Scripts/Video/` 도구).
2. 게임을 리플레이/봇 입력으로 같은 장면까지 진행해 같은 시점을 캡처한다 (`--replay`, `--capture-ticks`).
3. 원작과 게임 프레임을 나란히 붙인 비교 시트를 만든다.
4. Opus 가 차이를 평가하고 다시 수정을 지시한다. 만족할 때까지 2~4 반복.
5. 비교 결과를 사용자에게 보여주고 확인을 받으면 다음 항목으로 넘어간다.

## 0단계: 기반

- 0-1. 코딩/설계 스타일 가이드 (`Docs/CodingStyle.md`)
- 0-2. 영상 도구: 구간 프레임 추출, 타임라인 인덱스 (장면별 시작/끝 시각), 원작-게임 비교 시트 생성
- 0-3. 장면 진입 도구: 특정 장면(버스, 강, 헬기, 보스 등)으로 바로 워프해 캡처하는 리플레이 세트

## 1단계: 공통 기반 버그

- 1-1. 애니메이션/스프라이트 데이터 깨짐 전수 점검 (NPC 가 갑자기 바뀜, 탱크가 미사일로 바뀜 등 클립 오매핑)
- 1-2. 피격 tint: 붉은 주황 깜빡임 (지속 유지 버그 수정)
- 1-3. 사격 규칙: 권총/파이어샷은 연타만 발사 (자동 연사 제거), 파이어샷 탄 크기 확대,
  헤비머신건은 한 번 입력에 사격 모션이 3~5발 진행, 이동 시 캔슬

## 2단계: 스테이지

- 2-1. 초반 NPC (꼬마, 노인) 깨짐 수정
- 2-2. 최후반부 맵 깨짐 수정
- 2-3. 적 배치 전체 재작성: 영상 기준으로 등장 위치/수/타이밍을 다시 잡는다

## 3단계: 대형 적 재설계 (기존 코드와 데이터 삭제 후 새로 작성)

- 3-1. 중간보스 버스: 시트 33825 재절단, 패턴/타이밍 영상 기준
- 3-2. 헬기: 시트 20642 재절단, 등장/공격/파괴 영상 기준
- 3-3. 최종보스 배틀쉽: 시트 40204 재절단, 전 페이즈 영상 기준

## 4단계: 전체 통합 검수

- 처음부터 끝까지 원작과 구간별 비교, 남은 차이 목록화와 수정
