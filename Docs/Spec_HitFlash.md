# 적 피격 플래시 (원작 MS2) 실측 사양

출처: `Assets/Source/videoplayback (2).mp4` (480x360, 29.5 fps). 1 영상 프레임 = 33.9 ms.
가정: 원작 60 Hz 게임을 29.5 fps 로 캡처 → 1 영상 프레임 ≈ 2 게임 틱 (60 Hz). [M]
측정 방법: 같은 픽셀을 OFF/ON 프레임에서 비교 (버스는 락 후 정지 → 위치 고정).

## 1. 버스 (MBTruck) 플래시

- 대상: 스프라이트 전체가 같이 깜빡인다 (70.5 s 전체 주황, 부분 플래시 아님). [H]
- 샘플 영역: 상층 크림색 패널 영상 x 300~380, y 120~200 (정지 프레임 71.12 OFF / 71.19 ON / 71.32 OFF).
- 픽셀 밝기 구간별 매핑 (OFF RGB → ON RGB):

| 밝기 구간 (OFF 평균 V) | OFF (R,G,B) | ON (R,G,B) | ΔRGB |
|---|---|---|---|
| 25~60 (어두운 그림자) | 73,34,13 | 163,75,10 | +90,+41,−3 |
| 60~100 | 115,79,43 | 189,112,40 | +74,+32,−3 |
| 100~140 | 155,123,76 | 223,147,66 | +68,+24,−10 |
| 140~180 | 190,164,123 | 239,181,110 | +49,+17,−13 |
| 180~255 (밝은 크림) | 232,212,172 | 249,219,159 | +17,+7,−13 |

- 전체 픽셀 선형 회귀 (r² 0.59~0.78, 노이즈 큼): R' = 0.607R + 120.7, G' = 0.746G + 52.4, B' = 0.842B + 1.8.
- 구간 기반 근사 (권장 기본값): R' = 0.54R + 123, G' = 0.81G + 48, B' = 0.94B − 2 (0~255 클램프). 어두운/밝은 구간은 ±5 이내, 중간 구간 R 이 −13~−16 어긋남.
- 해석: 가산 틴트가 아니다 (밝은 픽셀일수록 증가량이 작다). 어두운 픽셀이 붉게 크게 떠오르는 "스크린/보간형" 주황. 단순 Color Mod 나 Additive 하나로는 맞지 않는다. [M]
- 색 (대표값): 평상시 본체 (95,75,40) → 플래시 (168,96,33). 육안 "연한 붉은 주황". 

## 2. 깜빡임 주기 (버스, 70.4~75.6 s, 약 5.2 s 구간)

- 판정: 패널 주황 비율 orangeFrac > 0.2 를 ON 으로 분류 (ON 평균 0.40~0.56, OFF 0.02~0.07 로 명확 분리).
- ON 시작 간격 (프레임): 6 프레임 (0.203 s) 이 최빈값, 평균 6.04 프레임. 4 프레임 (0.136 s) 도 다수. 최소 3 프레임 (0.102 s).
- ON 길이 3 프레임 / OFF 3 프레임 (6 프레임 주기) 이 기본. 2/2 (4 프레임 주기) 는 피격이 빠를 때.
- 연속 사격 중에도 주기가 유지되며, 피격마다 위상이 리셋되지 않는다 (자유 진행 블링크). [M]
- 흰 번쩍임 (white-hot): 피격마다 나타나지 않음. 72.14 s 1 프레임 (198,188,168) 만 관찰. [L]
- 단발 피격과 블링크 종료 조건은 영상에서 분리 불가 (항상 연사 중). [L]

## 3. 보스 (Big Shiee 캐논 헤드) 플래시 (역시 우측 상단 헤드 영역)

- 영역: 영상 x 335~400, y 10~110 (배경 하늘 포함, 평균값). 평상시 (100,88,73) 근처.
- 300.85~300.95 s: 4 프레임 ON (172,102,41) = 금빛 황주황. 첫 피격 플래시. [M]
- 301.02 s: 1 프레임 ON. 301.15~302.68 s: OFF 가 길게 이어짐 (사격 간격 공백).
- 302.71~302.98 s: 9 프레임 ON (152,102,66). 303.0~304.0 s: 2 프레임 on / 2 프레임 off (약 0.07~0.1 s 주기, 빠른 연사 시). [M]
- 결론: 보스도 같은 블링크 구조 (on/off 2~6 프레임). 금색 톤은 버스보다 덜 붉다 (G 상승 크고 R 상승 작음). 전용 LUT 은 아직 측정 안 함. [L]

## 4. 탱크/지프/헬기 (정성)

- 100~123 s 탱크 (바퀴 달린 수레형) 피격 시 주황/흰 순간 플래시 확인 (101~104 s, 107 s). 정량 측정 안 함. [L] 전체 스프라이트, 부위별 분리 없음.

## 5. 구현 (확정, 2차 실측 반영)

### 5.0 2차 실측 (V1 30 fps 프레임 단위, V2 29.5 fps) 요약
- 판정: 오렌지 비율 (R>190, 90<G<190, B<90) 이 영상 프레임별로 0.2 이상이면 ON.
- 버스 V1 1:10.0~1:11.3 (연사 초반): ON/OFF 가 매 프레임 교대 (`.#.#.#.#`), 간헐적으로 `###` 가 끼어 든다. 이후 3 프레임 주기 (`##.##.`, `#..#..`).
- 버스 V2 70.4~72.5: `###...###...` (3 on / 3 off) 가 여러 주기 정확히 반복. 전차 V2 2:21~2:25: 주기 4 프레임에 ON 길이가 3 -> 2 -> 1 프레임으로 줄어든다 (`###.###.` -> `##..##..` -> `#...#...`).
- 고립된 단발 피격 (V1 전차 2:50.5 등): 1 프레임 (약 2 틱) 만 ON.
- 결론: 피격 한 번 = 짧은 ON 펄스 하나. 연사 간격 (HMG 약 4~8 틱) 이 펄스보다 길면 `#..#..` 로 깜빡이고, 짧으면 `#.#.` 로 거의 교대한다. 연사 중에도 켜진 채 유지되지 않는다. 전체 평균 듀티 약 0.5 (버스 V1 첫 60 프레임 29 ON).
- 색: 가산 틴트가 아니라 "밝기 -> 주황 램프" 매핑이다 (그레디언트 맵). 같은 스프라이트의 OFF/ON 프레임 쌍 3개 (V1 버스 70.067/70.100 등) 로 평균 밝기 L=(R+G+B)/3 구간별 출력 평균을 구했다:

| L | 출력 RGB | L | 출력 RGB |
|---|---|---|---|
| 8 | 151,56,0 | 120 | 243,154,54 |
| 24 | 159,61,0 | 136 | 249,163,65 |
| 40 | 186,80,3 | 152 | 249,182,98 |
| 56 | 190,90,9 | 168 | 253,198,115 |
| 72 | 200,106,21 | 184 | 254,210,130 |
| 88 | 216,126,36 | 200 | 255,221,145 |
| 104 | 228,140,47 | 232 | 255,248,207 |

  (잔차 RMSE 약 14: 스프라이트 지터 포함. 채널별 1D LUT 이나 3x3 행렬보다 램프가 같거나 더 잘 맞았다.) 전차(V2 2:21.5) 도 같은 주황 계열. 정크선(V2 2:00.7) 은 변화량이 훨씬 작다 (R+40, G+20, B+8) [L] -> 이번 구현은 공통 램프만 쓴다.
- 대상: 스프라이트 전체 (부위별 아님). 치명타 프레임은 폭발이 덮어서 플래시를 확인할 수 없다.

### 5.1 렌더 (Source/Render/SpriteBatch.*)
- 아틀라스 페이지를 올릴 때 램프 변환본 텍스처를 한 벌 더 만든다 (`ApplyHitFlashRamp`, 알파 유지). 플래시 프레임은 ADD 패스 없이 변환본 텍스처로 그린다 (`SpriteDrawOptions::flashAmount >= 0.5`).
- 이전 구현: 원본 위에 ADD (255,110,40) x 알파 0.5 를 덧그렸다. 색이 원작 (램프) 과 달랐고, 아래 타이밍 버그 때문에 항상 켜져 있었다.

### 5.2 타이밍 (Source/Game/Combat/HitFlash.h)
- 피격 한 번 = ON 3 틱 + OFF 3 틱 펄스. 타이머는 피격 시 `kHitFlashTicks` (= on + gap + 1 = 7) 로 채우고 매 틱 감소, 값이 `3 < 값 < 7` 이면 ON (피격 이벤트가 Tick 앞에서 처리되므로 보이는 첫 값은 6).
- ON 중 재피격은 무시, gap(OFF) 구간이나 꺼진 상태의 피격은 새 펄스를 시작한다 -> 연사 중에도 반드시 깜빡인다 (최소 주기 6 틱).
- "계속 빨갛게 유지" 버그의 원인: 이전 코드는 피격마다 타이머를 12 로 다시 채웠고 ON 판정이 `경과 틱 / 6` 이라 경과가 항상 6 미만으로 리셋되어 연사 중 영구 ON 이었다. 플레이스홀더/더미 (StageWorldHost, TrainingTargets) 도 5틱 고정 틴트였다 -> 같은 펄스 함수로 통일.
- 대상: `hp >= 20` 정의 (jeep, btank, missle_tank, sarubia, 보스 부위) 와 JSON `hitFlash`. 1 방에 죽는 보병은 원작처럼 플래시하지 않는다 [L, 영상에서 병사 단발 피격 플래시는 확인되지 않음].

### 5.3 파라미터 표
| 항목 | 값 | 근거 |
|---|---|---|
| 펄스 ON 길이 | 3 틱 | 단발 1 프레임, 연사 1~3 프레임 |
| 펄스 OFF 최소 길이 | 3 틱 | 평균 듀티 약 0.5 |
| 연사 중 재피격 | ON 중 무시 | 연사 중 깜빡임 유지 |
